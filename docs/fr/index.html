Politique de confidentialité — SaluteInOrdine

Dernière mise à jour : 21/11/2026  ·  Version : 1.1 (application SaluteInOrdine 1.0.2)
Ceci est une traduction. Le texte de référence est la version italienne : en cas de différence entre les versions, la version italienne prévaut.
En bref.
  • Vos données de santé et celles de votre famille restent uniquement sur votre téléphone. Nous ne les envoyons à aucun serveur, ni chez nous ni ailleurs. Nous ne les voyons pas et, si vous les perdez, nous ne pouvons pas les récupérer.
  • Pas d'inscription ni de compte. Pas de publicité, pas de statistiques d'utilisation, pas de rapports d'erreur automatiques, pas d'intelligence artificielle. Le site compte seulement, sous forme de nombres par jour et sans identifiant, combien de fois les apps vérifient les mises à jour et combien de mises à jour sont téléchargées (point 5).
  • La lecture du texte des photos se fait entièrement sur le téléphone : photos et texte ne vont à personne (point 3.5).
  • Le bouton « Appeler à l'aide » appelle les numéros que vous choisissez, dans l'ordre que vous décidez. Les numéros restent sur le téléphone. Ce n'est pas un service d'urgence : en cas d'urgence, appelez le 112 ou le numéro d'urgence de votre pays (point 3.8).
  • Vous pouvez créer plusieurs profils (par exemple pour vos enfants ou pour un parent dont vous vous occupez). Les profils des mineurs sont gérés par un parent ou un tuteur.
  • Les données ne quittent le téléphone que lorsque vous créez un fichier (sauvegarde chiffrée, PDF ou CSV) et l'enregistrez ou le partagez, ou lorsque vous passez un appel.
  • L'application se connecte à internet uniquement pour activer Premium et pour vérifier et télécharger les mises à jour (points 4 et 5). Ces connexions ne contiennent aucune donnée de santé.
  • SaluteInOrdine est une archive et un agenda. Elle ne remplace ni le médecin, ni le dossier médical électronique de votre pays, ni les services d'urgence (point 13).

C'est pourquoi nous avons conçu l'application de sorte que les données de santé ne nous parviennent jamais, et nous expliquons dans cette politique comment elles sont protégées sur le téléphone.

3. Les données que vous saisissez dans l'application

3.1 Pays

Au premier lancement, vous choisissez votre pays. Il sert uniquement à afficher les bons champs et le numéro d'urgence du pays : pour l'Italie, par exemple, code fiscal, carte sanitaire, autorité sanitaire locale (ASL), exonérations du ticket modérateur et références au dossier médical électronique italien (FSE) ; pour les autres pays, des champs génériques. Ce choix reste sur le téléphone, vous pouvez le modifier dans les réglages et il n'est envoyé à personne. Le pays et la langue utilisée pour lire le texte des photos sont enregistrés dans les préférences de l'application, sur le téléphone ; la liste des numéros d'urgence est incluse dans l'application. Si vous choisissez un pays autre que l'Italie, le code fiscal et les exonérations déjà saisis restent enregistrés mais ne sont pas affichés.

3.2 Ce que vous pouvez enregistrer

Pour chaque profil, vous pouvez enregistrer, si vous le souhaitez, les informations suivantes. Presque tous les champs sont facultatifs.

  • profil : nom, date de naissance, mineur ou non, photo, sexe, langue parlée, parent ou tuteur de référence ;
  • données administratives : en Italie code fiscal, numéro et échéance de la carte sanitaire, ASL ou Région ; dans les autres pays les champs génériques prévus par l'application (voir point 3.3) ;
  • exonérations du ticket (Italie uniquement) : code tel qu'il figure sur le document, description, échéance ;
  • contacts : médecin traitant ou pédiatre, pharmacie, spécialistes, contact d'urgence avec le lien (par exemple « fille ») ;
  • allergies et intolérances, avec la réaction décrite par vous ;
  • affections : maladies actuelles ou passées, y compris handicaps, organes manquants et greffes ;
  • médicaments : nom, heures des rappels que vous choisissez, notes libres et journal des prises (« pris » ou « sauté ») ;
  • groupe sanguin, avec le compte rendu dont vous l'avez tiré, le cas échéant ;
  • vaccinations, avec date et certificat joint ;
  • interventions et hospitalisations, avec l'éventuelle lettre de sortie ;
  • dispositifs et implants (par exemple stimulateur cardiaque, prothèse, appareil auditif) ;
  • consultations et examens, avec comptes rendus, photos et documents joints et les questions à poser au médecin ;
  • « Mes champs » : des champs que vous créez, avec le nom et le contenu de votre choix. Pour chacun, vous choisissez de l'afficher ou non sur la fiche pour le médecin ou sur la fiche d'urgence ; par défaut il n'apparaît sur aucune. « Mes champs » figurent toujours dans le PDF complet du profil et dans le CSV, et jamais dans les notifications.

Il s'agit en grande partie de données concernant la santé, que le RGPD considère comme des catégories particulières de données (art. 4, point 15, et art. 9). Ce que vous écrivez dans « Mes champs » peut l'être aussi : c'est vous qui décidez de ce que vous y écrivez. Tout reste uniquement dans la mémoire privée de l'application sur votre téléphone, dans une base de données chiffrée ; les pièces jointes sont également chiffrées (détails au point 12).

Elles ne sont transmises à personne. Nous n'avons aucun serveur qui les reçoit, nous ne pouvons pas les lire et nous ne pouvons pas les récupérer si vous les perdez.

3.3 Code fiscal, carte sanitaire et numéros d'identification

Ils sont facultatifs. Dans l'application ils sont entièrement masqués : vous ne les voyez que dans le formulaire de modification du profil, en touchant l'icône en forme d'œil, et ils n'apparaissent sur aucun autre écran. Ils ne sont pas inclus dans les PDF et CSV que vous exportez, sauf si vous le choisissez au moment de l'export. Ils n'apparaissent jamais sur la fiche d'urgence ni dans les notifications et ne sont jamais utilisés pour activer Premium. Ils sont en revanche inclus dans la sauvegarde chiffrée (point 3.10), qui sert à restaurer toutes vos données. Il en va de même pour le champ d'identification générique utilisé hors d'Italie.

3.4 Photos et documents

Vous pouvez joindre des photos, des PDF et d'autres documents en les choisissant avec le sélecteur de fichiers ou de photos d'Android, qui ne transmet à l'application que le fichier choisi. Pour prendre une photo, l'application ouvre l'appareil photo du téléphone, qui ne lui renvoie que la photo prise : SaluteInOrdine ne demande pas l'autorisation de l'appareil photo ni l'accès à la mémoire du téléphone. Les fichiers sont copiés dans la mémoire privée de l'application, chiffrés, avec des noms neutres ; ils ne quittent pas le téléphone, sauf si vous les exportez ou les partagez.

3.5 Lecture du texte des photos

Si vous le souhaitez, l'application peut lire le texte d'un compte rendu ou d'un certificat photographié pour préremplir les champs. Le texte lu vous est toujours montré : vous le vérifiez et le confirmez avant son enregistrement. L'application n'interprète pas le contenu, n'extrait pas de valeurs et ne les juge pas. La lecture peut se tromper.

La lecture utilise Tesseract, un moteur de reconnaissance de texte open source qui fonctionne entièrement sur le téléphone. La photo et le texte lu ne sont envoyés à personne, ni à nous ni à des tiers, et la lecture n'envoie aucune donnée technique à un service externe.

Les modèles de langue de Tesseract (italien, anglais, espagnol, français, allemand et portugais) sont inclus dans l'application : ils ne sont pas téléchargés depuis internet. À la première utilisation, ils sont copiés dans la mémoire privée de l'application, exclue des sauvegardes. Pendant la lecture, l'application n'utilise pas le réseau. Les licences des composants (tesseract_ocr, BSD-3-Clause ; Tesseract4Android, Apache-2.0) se trouvent dans Informations › Licences.

3.6 Rappels et notifications

Les rappels pour les médicaments, les consultations, les vaccinations et les échéances (par exemple carte ou exonération) sont définis par vous : jour, heure et texte. L'application ne suggère ni heures ni quantités. Les notifications sont programmées et affichées par le téléphone : elles ne passent par aucun serveur, ni le nôtre ni celui de Google.

Pour ne pas montrer de données de santé à qui regarde votre téléphone, par défaut les notifications indiquent seulement « SaluteInOrdine – Vous avez un rappel ». Dans les réglages, vous pouvez choisir d'afficher aussi le nom du médicament (y compris pour le renouvellement de l'ordonnance), de la consultation ou du vaccin ; pour les exonérations, seule la mention « Exonération bientôt expirée » apparaît, sans le code ; le nom du profil, le code fiscal et les affections n'apparaissent jamais. Les notifications sont marquées comme privées : sur l'écran de verrouillage, Android peut en masquer le contenu, selon les réglages de votre téléphone.

Le journal « pris » ou « sauté » est un carnet que vous remplissez : l'application ne modifie ni les heures ni les rappels en fonction de ce que vous enregistrez.

3.7 Fiche d'urgence et fiche pour le médecin

Avec les données que vous avez saisies, l'application compose une fiche d'urgence (par exemple groupe sanguin, allergies, affections importantes, médicaments signalés, dispositifs, contact d'urgence, médecin, « Mes champs » que vous avez choisi d'afficher) et une fiche pour le médecin plus complète. Vous les voyez dans l'application ; avec Premium, vous pouvez les enregistrer en PDF.

Quiconque voit la fiche, ou le PDF, lit les données qu'elle contient. C'est vous qui choisissez les informations à inclure. Un PDF imprimé ou enregistré dans une autre application n'est plus protégé par le verrouillage de SaluteInOrdine.

SaluteInOrdine n'affiche pas de données de santé sur l'écran de verrouillage du téléphone. L'application peut vous expliquer comment copier certaines données dans les informations d'urgence d'Android : c'est une fonction d'Android, pas la nôtre. Google avertit que toute personne qui prend votre téléphone peut voir ces informations même lorsque le téléphone est verrouillé, et que vous pouvez les désactiver depuis l'application Sécurité personnelle (guide Google).

3.8 « Appeler à l'aide »

« Appeler à l'aide » est un bouton pour appeler rapidement les personnes que vous choisissez : par exemple un proche, votre médecin ou le numéro d'urgence de votre pays. Au début, l'application vous demande de saisir ces numéros comme première étape, et vous le rappelle tant que ce n'est pas fait.

  • Vous décidez des numéros et de leur ordre. Vous pouvez mettre en premier un proche qui habite tout près, puis le numéro d'urgence, ou l'inverse.
  • Les numéros et les noms restent uniquement sur le téléphone, dans la base de données chiffrée de l'application. Nous ne les envoyons à personne et ne les recevons pas. Vous pouvez saisir les numéros ou les choisir avec le sélecteur de contacts d'Android : l'application reçoit uniquement le nom et le numéro du contact choisi et n'a pas l'autorisation de lire vos contacts.
  • Préavis de 5 secondes. Lorsque vous appuyez sur « Appeler à l'aide », l'application affiche pendant 5 secondes qui elle va appeler, avec un bouton Annuler ; ensuite l'appel part tout seul.
  • Autorisation d'appel. Pour lancer l'appel toute seule, l'application a besoin de l'autorisation Android « Téléphone – passer et gérer des appels » (CALL_PHONE). Elle vous la demande une seule fois, après une explication, lorsque vous enregistrez la première personne. Si vous ne l'accordez pas, l'application ouvre le clavier du téléphone avec le numéro déjà saisi et c'est vous qui lancez l'appel.
  • Numéros d'urgence. Android ne permet pas aux applications de lancer d'elles-mêmes un appel vers les numéros d'urgence (par exemple le 112) : pour ces numéros, l'application ouvre le clavier avec le numéro déjà saisi et vous appuyez sur la touche d'appel.
  • Appeler le suivant. Après un appel, vous pouvez passer à la personne suivante de la liste, avec un nouveau préavis de 5 secondes. Si la liste est vide, « Appeler à l'aide » propose le numéro d'urgence du pays choisi.
  • Toujours accessible, même sans code PIN. « Appeler à l'aide » s'ouvre au-dessus de l'écran du code PIN et depuis le menu qui apparaît en appuyant longuement sur l'icône de l'application. C'est voulu : en cas d'urgence, le bouton ne doit pas être bloqué. Cela signifie toutefois que toute personne qui a en main votre téléphone, même avec l'application verrouillée, peut voir les noms de vos contacts d'aide et lancer un appel. Lorsque l'application est verrouillée, seuls les noms et le numéro d'urgence du pays sont visibles, pas les autres numéros ; le reste des données reste protégé par le code PIN. Vous seul pouvez lancer « Appeler à l'aide », depuis l'application ou le menu de l'icône : les autres applications installées sur le téléphone ne peuvent pas lancer l'appel via SaluteInOrdine.
  • L'appel est un appel téléphonique normal, géré par votre téléphone et votre opérateur, au coût de votre forfait. La personne appelée voit votre numéro de téléphone, comme pour tout appel (sauf si vous avez masqué votre numéro dans les réglages du téléphone). SaluteInOrdine n'enregistre pas l'appel, n'envoie pas de SMS, n'envoie ni votre position ni des données de santé et ne garde pas de liste des appels passés.
  • Pas de détection des chutes. L'application ne détecte ni chutes ni malaises et n'appelle personne d'elle-même : l'appel ne part que si vous appuyez sur le bouton.

L'application peut aussi vous expliquer comment activer la fonction SOS d'urgence d'Android : c'est une fonction d'Android, pas la nôtre, qui suit les règles d'Android et du fabricant du téléphone.

« Appeler à l'aide » n'est pas un service d'urgence et ne garantit pas que quelqu'un réponde : l'appel peut échouer, par exemple sans réseau, sans crédit ou téléphone éteint. En cas d'urgence, appelez le 112 ou le numéro d'urgence de votre pays.

Les numéros que vous saisissez sont des données d'autres personnes (proches, médecin) : saisissez-les seulement si elles acceptent d'être appelées en cas de besoin.

3.9 Export et partage (Premium)

Avec Premium, vous pouvez exporter les données en PDF ou en CSV. Le fichier est créé sur le téléphone, puis c'est vous qui l'enregistrez ou le partagez, avec l'application de votre choix (e-mail, WhatsApp, Drive, impression). Le fichier ne passe pas par nos serveurs.

Les fichiers PDF et CSV ne sont pas chiffrés et n'ont pas de mot de passe. Le code fiscal et le numéro de carte sanitaire ne sont inclus que si vous cochez la case prévue lors de l'export. Une fois sortis de l'application, ils sont traités par le destinataire ou par le service où vous les enregistrez, selon ses propres règles. Ne les partagez qu'avec des personnes de confiance, par exemple votre médecin. L'application n'offre pas d'accès partagé : la seule façon de montrer les données à quelqu'un est un fichier que vous créez.

3.10 Sauvegarde chiffrée

Depuis les réglages, vous pouvez créer un fichier de sauvegarde chiffré avec un mot de passe de votre choix. Le mot de passe n'est ni enregistré ni communiqué à quiconque. Le fichier est chiffré en AES-256-GCM ; la clé est dérivée du mot de passe avec PBKDF2-HMAC-SHA256 (600 000 itérations). Vous décidez où l'enregistrer. Nous ne le recevons pas et ne pouvons pas l'ouvrir.

La sauvegarde contient toutes les données de tous les profils, y compris code fiscal, carte sanitaire, « Mes champs », les numéros d'« Appeler à l'aide » et toutes les pièces jointes (photos et documents). Elle ne contient ni la licence Premium, ni le code PIN, ni les réglages de l'application. La restauration remplace les données présentes sur le téléphone par celles de la sauvegarde. Si vous restaurez une sauvegarde créée avec une version antérieure de l'application, sans « Appeler à l'aide », les numéros d'aide déjà présents sur le téléphone sont conservés.

Si vous oubliez le mot de passe, la sauvegarde ne peut pas être ouverte, pas même par nous.

Pour garder les données de santé hors du cloud, l'application exclut ses données de la sauvegarde automatique d'Android sur Google Drive et du transfert de téléphone à téléphone : aucune donnée de SaluteInOrdine ne se retrouve dans la sauvegarde de votre compte Google. Si vous changez de téléphone, vous emportez vos données avec votre fichier de sauvegarde.

3.11 Données des proches et des mineurs

Vous pouvez créer des profils pour d'autres personnes, par exemple vos enfants ou un parent âgé dont vous vous occupez. Ce sont des données de santé d'autres personnes : saisissez-les seulement si vous vous occupez de leur santé.

  • Mineurs : leurs profils sont créés et gérés par un parent ou un tuteur, sur son propre téléphone. L'application ne demande pas aux mineurs de s'inscrire et ne collecte pas de données auprès d'eux.
  • Autres adultes : nous vous conseillons de le faire avec leur accord et de leur montrer ce que vous avez enregistré. S'ils le demandent, corrigez ou supprimez leurs données.
  • Les données des proches, comme les vôtres, restent uniquement sur votre téléphone et ne sont jamais utilisées pour activer Premium.

3.12 Verrouillage de l'application

Au premier lancement, l'application vous propose de la protéger par un code PIN (4 à 8 chiffres) et, si vous le souhaitez, par l'empreinte ou le visage reconnus par le téléphone. Ce n'est pas obligatoire. Le code PIN n'est pas enregistré en clair : l'application n'en conserve qu'une empreinte (hash PBKDF2). La reconnaissance de l'empreinte ou du visage est faite par Android : l'application ne reçoit que le résultat.

Le code PIN protège l'accès à l'application, il ne chiffre pas les données : le chiffrement de la base de données et des pièces jointes est toujours actif, avec des clés conservées par le téléphone (point 12), même sans code PIN. Lorsque l'application passe en arrière-plan, elle se verrouille après le délai que vous choisissez (1 minute par défaut ; vous pouvez choisir « immédiatement » ou 5 minutes). « Appeler à l'aide » reste accessible même lorsque l'application est verrouillée (point 3.8).

Si vous oubliez le code PIN, nous ne pouvons pas le récupérer : vous pouvez déverrouiller avec l'empreinte ou le visage, s'ils sont activés, ou utiliser « Supprimer toutes les données » et restaurer une sauvegarde.

Par défaut, l'application empêche les captures d'écran et masque son contenu dans la liste des applications récentes sur tous les écrans. Vous pouvez désactiver cette protection dans les réglages.

4. Activation de Premium sur le téléphone

Une clé Premium est valable sur 2 téléphones au maximum. Pour faire respecter cette limite, lorsque vous activez la clé, l'application se connecte à notre serveur de licences (licenze.hubertmontero8514.workers.dev, un service Cloudflare Workers que nous gérons) et envoie :

  • le nom de l'application (saluteinordine) ;
  • la clé de licence, qui contient l'adresse e-mail de l'acheteur, le forfait et la date d'expiration ;
  • une empreinte du téléphone : un code obtenu par une fonction de hachage (SHA-256) à partir du nom de l'application et de l'identifiant Android du téléphone (ANDROID_ID), puis raccourci à 22 caractères. L'identifiant Android n'est jamais envoyé en clair et l'empreinte est différente pour chaque application : elle ne permet donc pas de relier votre usage de différentes applications.

Ces requêtes ne contiennent aucune donnée de profil, de santé ou d'« Appeler à l'aide ». La même requête est répétée automatiquement lorsque l'activation est sur le point d'expirer (moins de 20 jours) et seulement si le téléphone est connecté ; elle est aussi faite lorsque vous appuyez sur Désactiver sur ce téléphone. Il n'y a pas d'autres requêtes vers le serveur de licences. Le serveur répond par une activation signée que l'application vérifie sur le téléphone, même hors connexion.

Le serveur de licences ne conserve pas votre e-mail ni la clé en clair. Il conserve uniquement : le hash SHA-256 de la clé ; l'empreinte du téléphone ; le type de forfait ; la date d'activation et celle du dernier renouvellement ; si vous changez de téléphone, la date du dernier remplacement automatique (un tous les 30 jours) ; si une clé est bloquée (par exemple après un remboursement ou un abus), le hash de cette clé. Le bouton Désactiver sur ce téléphone, dans l'écran Premium, supprime du serveur la ligne qui lie la clé à ce téléphone.

L'identifiant Android n'est lu que pour activer Premium, jamais pour la publicité, les statistiques ou le profilage.

5. Mises à jour de l'application

Au lancement, l'application demande à marketplace-apps.com/api/versione/saluteinordine quelle est la dernière version et, s'il y en a une nouvelle, télécharge le paquet en passant par marketplace-apps.com/api/scarica/saluteinordine, qui renvoie aussitôt vers le fichier sur files.marketplace-apps.com (Cloudflare R2). C'est vous qui confirmez l'installation. Ces requêtes ne contiennent ni données de santé ni identifiants du téléphone ou de la licence.

Le site n'enregistre ni l'adresse IP ni d'autres données de ces requêtes : il ne garde que des nombres par jour, c'est-à-dire combien de fois les apps ont demandé la version (ce sont des ouvertures, pas des personnes) et combien de mises à jour ont été téléchargées, par app et par version. Ces nombres ne permettent d'identifier personne. Du serveur de licences aussi, nous ne tirons que des nombres globaux par app (téléphones activés, téléphones connectés au cours des 30 derniers jours, activations et ventes par jour), sans voir d'empreintes, de clés ni d'e-mails.

Comme tout serveur, les prestataires d'infrastructure (Cloudflare pour le serveur de licences et les fichiers, Vercel pour le site, y compris le passage des téléchargements des mises à jour) enregistrent des données techniques des requêtes, comme l'adresse IP, le type de client (User-Agent) et l'heure. Ces journaux sont conservés selon les politiques des prestataires, indiquées dans leurs politiques de confidentialité (Cloudflare, Vercel).

12. Sécurité

  • Base de données chiffrée : les données des profils, « Mes champs » et les numéros d'« Appeler à l'aide » se trouvent dans une base SQLite chiffrée en ChaCha20-Poly1305 (SQLite3MultipleCiphers). La clé est une séquence aléatoire de 32 octets générée sur le téléphone et protégée par l'Android Keystore. Les données supprimées sont écrasées dans la base (secure delete).
  • Pièces jointes chiffrées : photos et documents sont chiffrés en AES-256-GCM, avec une clé distincte protégée par l'Android Keystore, et enregistrés sous des noms neutres.
  • Sauvegarde chiffrée : AES-256-GCM avec une clé dérivée de votre mot de passe (point 3.10).
  • Verrouillage de l'application par code PIN ou biométrie et protection contre les captures d'écran active par défaut (point 3.12).
  • Pas de sauvegarde automatique des données chez Google ni de transfert automatique de téléphone à téléphone (point 3.10).
  • Les communications avec le serveur de licences et pour les mises à jour se font en HTTPS.

Aucune mesure n'est infaillible : quiconque connaît le code PIN ou déverrouille le téléphone peut voir les données dans l'application, et quiconque a le téléphone peut utiliser « Appeler à l'aide ». Nous vous conseillons de garder le verrouillage de l'écran actif, de mettre à jour le système et de faire des sauvegardes régulières : si vous perdez ou réinitialisez le téléphone sans sauvegarde, les données ne sont pas récupérables.

13. L'application ne remplace ni le médecin, ni le dossier médical électronique, ni les services d'urgence

SaluteInOrdine est une archive et un agenda des données de santé que vous saisissez. Elle ne pose pas de diagnostic, ne donne pas de conseils médicaux, ne calcule ni ne suggère de doses, ne vérifie pas les interactions médicamenteuses, ne signale pas de valeurs anormales et n'interprète pas les comptes rendus.

C'est vous qui saisissez les données : l'application ne vérifie pas qu'elles sont complètes ou correctes. Ce n'est ni un dossier médical électronique ni un service de santé de votre pays et elle ne les remplace pas ; pour les documents officiels, font foi ceux délivrés par les établissements de santé.

« Appeler à l'aide » n'est pas un service d'urgence. Pour toute question de santé, adressez-vous à votre médecin ou à votre pharmacien. En cas d'urgence, appelez le 112 ou le numéro d'urgence de votre pays.
